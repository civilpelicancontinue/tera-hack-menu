## 🧩 About

**TERA Companion** is a curated list of TERA open-source tools:

- **Overlays** — on-screen helpers, layout notes, cooldown timers, map reader
- **Quality-of-Life Helpers** — inventory catalog, skill notes, config presets
- **Research Notes** — dungeon layouts and class rotation notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Cooldown Tracker — monitor skill timers on screen
- Skill Range Notes — visualize ability ranges for study
- Rotation Notes — record and review class rotations
- Combat Log — review damage and healing events

### Wallhack
- Item Catalog — browse gear, glyphs, and costumes
- Custom UI Notes — organize interface layouts
- Mount & Pet Index — track collectibles

### Aimbot
- Map Reader — overlay dungeon and zone maps
- Node Tracker — note gathering node positions
- Quest Layout Notes — plan route studies
